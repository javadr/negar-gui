# Changelog

## [1.4.10] - 2026-11-11

### Fixed
- Full Screen Input (Ctrl+F) now fills the whole window width and hides the comparison-mode checkbox

## [1.4.9] - 2026-11-11

### Changed
- OCR language is a multi-selection: tick any combination of Persian, English and Deutsch (at least one stays on); the choice is saved

## [1.4.8] - 2026-11-11

### Fixed
- Windows and Linux executables had no dark theme: the original pyqtdarktheme is capped at Python <3.12 and pip fell back to a theme-less 0.1.7. Now depends on pyqtdarktheme-fork (same `qdarktheme` module, Python 3.8-3.14)
- PyInstaller builds now bundle the qdarktheme data files (`--collect-data qdarktheme`)
- Release workflows replace the original pyqtdarktheme pulled in by an older negar-gui; Dockerfile no longer needs its forced 2.1.0 install

## [1.4.7] - 2026-11-11

### Changed
- Gemini is the default AI provider (the provider dialog opens when no key is set); providers are listed Gemini, OpenAI, Groq, OpenRouter, Pollinations
- The AI menu is now called "Assistant" (دستیار)
- Usage charts run oldest to newest from left to right with the y-axis on the left in both languages; the y-axis uses Persian digits in Persian mode

## [1.4.6] - 2026-11-11

### Changed
- OCR has its own menu (screen reader, clipboard image reader, language); menu order is File, Edit, View, OCR, Assistant, Settings, Help
- Assistant menu entries (Manage Prompts, AI Provider, Usage Report) are defined in the Qt Designer file

## [1.4.5] - 2026-11-10

### Added
- Toolbar buttons for the screen reader and the clipboard image reader

## [1.4.4] - 2026-11-10

### Added
- Tesseract (fas/eng/deu) is bundled in the Linux and Windows executables

### Fixed
- QtDBus is optional; stdin handling; Tesseract lookup on Windows and macOS

## [1.4.3] - 2026-11-10

### Changed
- OCR menu group with icons below the QR code entry; the OCR language is saved and survives screen capture

## [1.4.2] - 2026-11-10

### Added
- Read text from a clipboard image (Ctrl+Alt+O)

## [1.4.1] - 2026-11-10

### Added
- Screen reader: select a screen region and read its text with Tesseract (fas/eng/deu); portal capture on Wayland
- Persian menus for the screen reader

## [1.3.3] - 2026-11-09

## [1.1.0] - 2026-11-06

### Added
- Choose the AI provider (Gemini, Groq, OpenRouter, OpenAI) with your own API key, model override and a link to get a key; the dialog opens when a key is missing
- Clear messages for rejected keys (401/403) and rate limits (402/429), without retrying them
- Settings file is owner-only since it stores keys

## [1.0.6] - 2026-11-06

### Added
- Switch the keyboard to Persian on startup and restore it on close (Windows, macOS, KDE Plasma, Sway, X11, GNOME via Shyriiwook); toggle in the Settings menu

## [1.0.5] - 2026-11-06

### Fixed
- Consistent font resizing for both editors; zoom popup (pt and %) on Ctrl+wheel, slider and shortcuts; Ctrl++ works with the keypad; font slider stays LTR; input editor gets focus on startup

## [1.0.4] - 2026-10-31

### Fixed
- App name in Alt+Tab/taskbar now shows "Negar" instead of "python3" (set app id and StartupWMClass)

## [1.0.3] - 2026-10-31

### Fixed
- Menus stay open when toggling checkable items; close with ESC or an outside click

## [1.0.2] - 2026-07-19

### Fixed
- Version update notification ("New version is available...") now translated
  in Persian mode
- Version notification re-translates on language switch mid-session
- AI icon now renders correctly via Qt resources (regenerated
  `resource_rc.py` with `ai.svg`)

## [1.0.1] - 2026-07-19

### Fixed
- GNOME Wayland crash on `make lins`/`make pins` (race condition writing
  `negar.desktop` — write to temp file then atomic rename)
- AI icon not visible when installed from PyPI (`make pins`) — load from
  Qt resources instead of filesystem; bundle all icons in the wheel

## [1.0.0] - 2026-07-18

### Added
- AI grammar-fix button with Pollinations.ai integration (no API key required)
- `llm_providers.py` module with `PROMPTS` dict and `fix_text()` function
- Custom toolbar button + AI menu with spinning icon animation during requests
- `Ctrl+Shift+A` hotkey for the AI grammar-fix button
- Persian translations for the AI menu and all status bar messages
- Auto-retry (2 attempts) on API failure with 1s delay

### Changed
- Status bar now uses `\u202B`/`\u202C` Unicode directional formatting for correct Persian rendering
- Status bar re-translates on language switch (including mid-job "Running..." message)
- Menubar and application layout direction now properly follow the selected language

### Fixed
- Status bar alignment respects Persian (RTL) and English (LTR) modes
- Menus and submenus open on the correct side in Persian mode
