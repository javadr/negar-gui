Negar-GUI Help

Negar-GUI edits Persian text: it fixes spacing, half-spaces (ZWNJ), punctuation and digits, and can also rewrite text with an AI assistant. Type or paste text in the input box and the corrected text appears in the output box.

Contents: Getting started · Editing options · Views · OCR · AI assistant · Untouchable words · Settings · Shortcuts · Links

Getting started

  • Type, paste (Ctrl+V) or open a file (Ctrl+O) into the input box.
  • Press Edit, or tick Automatic edit to edit while you type.
  • Copy the result with Ctrl+C, or save it with Ctrl+S / Ctrl+Shift+S. Closing the window with Esc copies the output to the clipboard.
  • Ctrl + mouse wheel, or the slider, changes the font size.

Editing options

The Edit menu lists every fix Negar can apply (dashes, three dots, quotes, hamzeh, Arabic/English digits, prefix and suffix spacing, kashidas, extra marks, whitespace, ZWNJ…). Each one can be switched on or off; Select All, Unselect All and Invert Selection change them in one go. Your choices are saved.

Views

  • Comparison mode – the checkbox under the output marks what changed against the original.
  • Side-by-Side View (Ctrl+I) – input and output next to each other instead of stacked.
  • Full Screen Input (Ctrl+F) – hides the output and uses the whole window for the input.
  • Theme – Dark, Light or Auto (Ctrl+T, then D or L).
  • Interactive Clipboard (Ctrl+B) – edits whatever you copy, automatically.

OCR – text from images

  • Read Text from Screen (Ctrl+Shift+O) – drag a rectangle over any part of the screen.
  • Read Text from Clipboard Image (Ctrl+Alt+O) – reads an image you have copied.
  • The OCR menu selects the languages (Persian, English, Deutsch); at least one stays on. The recognised text is put in the input box and edited.

AI assistant

  • Pick a prompt (for example proofreading, formal, academic or casual rewriting) in the toolbar list and press the AI button (Ctrl+Shift+A). The reply goes to the output box.
  • AI Provider… chooses the service and enters your API key and model.
  • Manage Prompts… lets you add, edit or hide prompts, in English and Persian.
  • Usage Report… shows requests and tokens used over time.

Your text is sent to the provider you choose; nothing is sent when you only use the normal editing.

Untouchable words

Edit → Untouchable Words keeps a list of words Negar must never change (names, brands, technical terms). Add a single word and press Add.

Settings

  • Settings → Language switches the interface between Persian and English.
  • Persian Keyboard on Startup switches your keyboard layout to Persian when Negar starts.
  • All options, the window layout and the font size are remembered between sessions.
  • Update Check tells you if a newer version is available.
